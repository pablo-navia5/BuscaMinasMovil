# 📌 Videojuego Buscaminas en Android

Proyecto de un Buscaminas para Andoid desarrollado como practica de 2º DAM.

## 🚀 Tecnologías Utilizadas

Para este trabajo he utilizado Kotlin para el desarrollo de la app movil, para la parte de la interfaz he utilizado el plugin de Jetpack Compose.

## ✨ Características Principales

*   Elección del tamaño del mapa
*   Aperturas de casillas vacías contiguas a la seleccionada
*   indicador numérico con cantidad de bombas al rededor de la casillas seleccionada
*   Pantalla de victoria / derrota

## 🛠️ Instalación y Ejecución local

Sigue estos pasos para probar el proyecto en tu entorno local:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/pablo-navia5/PacmanJava.git
   ```
2. Abre el proyecto en tu IDE
4. Ejecuta el proyecto
